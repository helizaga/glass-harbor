# Taste Examples

Use `examples/<slug>/` to teach Glass Harbor what you like without committing copyrighted audio.

Committed files:

- `examples/<slug>/example.md`
- `examples/<slug>/profile.json`

Local-only files:

- `examples/<slug>/clips/*.wav`
- `examples/<slug>/analysis.json`

Recommended clip naming:

- `anchor.wav`
- `groove.wav`
- `lift.wav`
- `breath.wav`
- `return.wav`
- `outro.wav`

The critic reads `profile.json`, not the raw clip files, during normal song review.
