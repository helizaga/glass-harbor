# Presets And Conventions

## Preload Ritual

1. Open the local app.
2. Switch to `Pack Preload`.
3. Press play once and let the pattern cycle.
4. Switch to `Local Preview` or `SuperDirt Performance`.

This front-loads the first browser fetch/decode pass for the mission-critical sample families.

## Sound Split

- Local sample engine:
  - drums
  - FX
  - vocal chops
  - atmospheres
- SuperDirt over OSC:
  - bass
  - pads
  - plucks
  - arps
  - leads
- Browser synths:
  - placeholder sketch voices only

## Naming

- Use descriptive family names, not genre pack names.
- Use one stable family name per role and grow variants through indexes inside that family.
- When replacing sounds, preserve the folder and file order unless you intend to rewrite patterns that use `n(...)`.
