# Reference Cards

Reference cards are abstract retrieval notes for prompting and critique.

They should capture:

- genre or mood tags
- BPM range
- section map
- energy curve
- active sound roles by section
- groove notes
- harmonic movement summary
- transition recipes

They should not contain:

- copyrighted lyrics
- full note-for-note transcriptions
- raw commercial audio
- vendor sample names

Use these cards to give the songwriter and critic patterns to aim at without turning the repo into a library of copied songs.
