# Reference: Breath Before Return

## Tags

- breath section

- tension reset
- minimal ingredients

## BPM Range

- 120-126

## Mood

- suspended
- poised
- expectant
- narrow

## Section Map

- drop: 16
- breath: 8
- second-drop: 16

## Energy Curve

- high -> medium-low -> high

## Active Sound Roles By Section

- drop: groove core plus tops and impact
- breath: `air_texture`, filtered groove fragments, sparse vocal
- second-drop: restored groove core plus the brightest withheld layer

## Groove Notes

- the breath should feel intentional, not empty
- preserve pulse with fragments, not full grooves
- return strongest material after the listener exhales

## Harmony Summary

- hold tonic gravity while reducing rhythmic information

## Transition Recipes

- filtered tail plus one breath of air
- reintroduce clap or bass on the first downbeat of the return

## Reusable Takeaways

- a short breath can make the final return feel larger
- less material can increase anticipation if pulse memory survives
