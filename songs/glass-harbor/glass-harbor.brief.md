# Glass Harbor

## Genre

Melodic house / progressive house with deep and chill crossover.

## Mood

Cinematic, late-night, reflective, polished, and warm.

## BPM

124

## Key / Scale

D minor center with lush suspended harmonic color.

## Structure

- 8-cycle intro
- 16-cycle first groove
- 8-cycle lift
- 16-cycle breakdown
- 16-cycle first drop
- 8-cycle breath
- 16-cycle second drop
- 8-cycle outro

## Sonic Goals

- strong but not aggressive four-on-the-floor foundation
- polished hats and tops with restrained brightness
- emotional pads and hook-forward melodic movement
- cinematic risers, impacts, shimmer, and air textures
- no raw vendor names in code

## Review Goals

- increase breakdown-to-drop contrast without making the groove brittle
- keep the top end polished rather than splashy
- preserve warm low-end weight while keeping the kick readable
- prefer 3 to 5 concrete revision actions over open-ended critique

## Stable Sound Roles

- `kick_main`
- `clap_main`
- `hat_closed`
- `hat_open`
- `perc_top`
- `impact_wide`
- `riser_up`
- `shimmer_fx`
- `air_texture`
- `vocal_chop`

## Notes For Agent

- keep the song as one pasteable `.strudel.js` file
- use stable sound roles only for sampled material
- keep tonal parts readable and modular
- the same file should work in Strudel web after `npm run song:serve`
