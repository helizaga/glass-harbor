# Strudel Quick Reference

These notes are the local, agent-friendly Strudel layer for Glass Harbor.

Use them when you need fast guidance without loading the full Strudel docs:

- [technique-index.md](/Users/tommy/Documents/GitHub/song/docs/strudel/technique-index.md)
- [sound-guide.md](/Users/tommy/Documents/GitHub/song/docs/strudel/sound-guide.md)
- [style-lanes.md](/Users/tommy/Documents/GitHub/song/docs/strudel/style-lanes.md)

What this is for:

- choosing the right Strudel technique for a musical problem
- choosing the right sound-role subset for a lane
- avoiding the repo’s default “same producer” accent across every song

What this is not for:

- replacing the official Strudel docs
- documenting every Strudel API in full
- prescribing one composition style for all genres
