# Sound Guide

This is the fast guide for how Glass Harbor’s sound roles should be used.

## Core Rhythm Roles

- `kick_main`
  - owns the rhythmic anchor
  - change pattern or sustain around it before widening it
- `clap_main`
  - owns backbeat shape
  - should clarify the lane, not just add noise
- `hat_closed`
  - best place for swing, feel, and pace
- `hat_open`
  - best used as sectional lift, not constant brightness
- `perc_top`
  - use for motion and accent drift, not as a generic filler lane

## Atmosphere / Transition Roles

- `air_texture`
  - background width and glue
- `shimmer_fx`
  - upper lift, intros, and transition polish
- `riser_up`
  - sparing lift into return sections
- `impact_wide`
  - first downbeat clarity, not constant trailer energy

## Vocal Role

- `vocal_chop`
  - should usually be split into jobs:
    - airy bed
    - hook punctuation
    - breakdown fragment
    - return accent

## Tonal Roles

- `bass_pitched`
  - preferred for note-driven basslines
- `stab_pitched`
  - harmonic bed or offbeat punctuation
- `pluck_pitched`
  - hook articulation, call-and-response, or light topline
- `bass_tonal`, `stab_tonal`, `pluck_tonal`
  - simpler character-shot fallback when pitched families are not the right move

## High-Leverage Role Combinations

For hook-first songs:

- `vocal_chop` + `pluck_pitched`

For loop-first house songs:

- `stab_pitched` + `bass_pitched`

For broken-grid club songs:

- `vocal_chop` + `bass_pitched` + `hat_closed`

For more atmospheric songs:

- `stab_pitched` + `air_texture` + restrained `pluck_pitched`

## What Not To Do

- use every role just because it exists
- let `air_texture` or `shimmer_fx` become the identity
- use `vocal_chop` as one repeated lane through the whole song
- let `hat_open` define the whole style
- use the same subset for every genre
